Repo build vg-chiaki cho VietGame.
1) Tạo repo GitHub MỚI (Private). 2) Upload toàn bộ nội dung thư mục này (gồm .github và native).
3) Vào tab Actions -> "Build vg-chiaki (Windows x64)" -> Run workflow.
4) Khi xong, mở lần chạy đó, mục Artifacts, tải vg-chiaki-win64.zip.
5) Giải nén vào D:\VG1\vg-chiaki\ (có vg-chiaki.exe cùng các file .dll).
Không đẩy file vietgame-keys.json hay dữ liệu cá nhân lên repo.
